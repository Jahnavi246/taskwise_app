# 📱 TaskWise - AI-Powered Student Academic Planner

TaskWise is a smart productivity and academic planning application designed to help students manage their schedules, track tasks, and stay organized.

---

## ✨ Features
* 📅 **Schedule & Calendar Management:** Keep track of daily classes, events, and academic deadlines.
* 📋 **Task Tracking:** Easily add, manage, and complete homework assignments and projects.
* 🔔 **Reminders & Notifications:** Stay updated on upcoming tasks and schedules.
* 🎨 **Clean UI:** Simple, modern, and user-friendly interface designed for mobile.

---

## 🛠️ Tech Stack & Tools
* **Framework:** [Flutter](https://flutter.dev/)
* **Language:** [Dart](https://dart.dev/)
* **IDE:** VS Code / Android Studio
* **Version Control:** Git & GitHub
